# Web勤怠管理システム (Attendance Management System)

本システムは、JavaおよびSpring Bootを用いて開発した、実務を意識したWebベースの勤怠管理システムです。
フロントエンドにはBootstrapを採用し、レスポンシブ対応かつ直感的な操作が可能なユーザーインターフェースを実現しています。

## 🎯 開発の動機
実務におけるWebアプリケーション開発の現場で広く使われている堅牢な言語である「Java」と、モダンな開発フレームワークである「Spring Boot」の習得を目的に作成いたしました。

Webシステムの基本である「画面からのデータ送信（POST処理）」「データベースへの保存・更新（JPA）」「データの画面表示（Thymeleaf）」という一連のバックエンド・フロントエンドの連動処理を一気通貫で自力で構築し、Webエンジニアとしての基礎的な開発スキルを形にしました。

## 🛠️ 使用技術 (Tech Stack)
* **バックエンド (Backend):** Java 17+ / Spring Boot 3.x
* **フロントエンド (Frontend):** HTML5 / CSS3 (Bootstrap 5) / JavaScript (デジタル時計実装) / Thymeleaf (テンプレートエンジン)
* **データベース (Database):** H2 Database (インメモリデータベース)
* **ORM / データアクセス:** Spring Data JPA / Lombok (開発効率化)
* **ビルドツール:** Maven
* **開発環境 (IDE):** IntelliJ IDEA

## ✨ 実装済み機能
1. **リアルタイムデジタル時計表示機能**
    * JavaScriptを用い、1秒ごとに正確な現在時刻を更新表示。
2. **出勤打刻機能 (Create / Insert)**
    * 「出勤」ボタンを押した際、現在の日付と出勤時刻をデータベースへ自動保存。
3. **退勤打刻機能 (Update / Upsert)**
    * 「退勤」ボタンを押した際、同日の既存データ（出勤レコード）を自動で検索し、退勤時刻のみを上書き更新（UPDATE処理）。出勤データがない場合は新規レコードとして安全に保存（Upsert処理）。
4. **打刻履歴の自動一覧表示機能 (Read / Select)**
    * Thymeleafの繰り返し処理（`th:each`）を使用し、データベース内の過去の全打刻履歴をテーブル形式でリアルタイムに画面へ描画。

## 💡 開発においてこだわった点・苦労した点
* **実務を意識したデータ設計:**
  退勤ボタンを押した際に、単に新しい行を増やすのではなく、「今日の出勤データを探して、同じ行の退勤時刻を上書きする」という、実務の業務システムで必須となるデータの整合性を意識したロジック（JPAによるUPDATE処理）を自力でコントローラーに実装しました。
* **トラブルシューティング能力の向上:**
  開発途中、データベースのテーブル未生成によるエラー（`Table "KINTAI_RECORDS" not found`）や、ブラウザのキャッシュによる動作不整合、IDEのフリーズに直面しましたが、ログを精読して原因を特定し、`application.properties` の設定変更（`ddl-auto=update`）や環境の最適化を行うことで、すべての問題を自己解決しました。
